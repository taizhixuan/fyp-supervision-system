# Committee Module Screen Descriptions

This document provides brief descriptions of each screen in the FYP Committee module of the FYP Supervision System.

---

## 4.5.1 Committee Dashboard
**URL:** `/committee/dashboard`

The Committee Dashboard provides a comprehensive overview of the entire FYP programme status. It displays key performance indicators including total proposals, pending reviews, unpaired students, and overloaded supervisors with visual alerts for items requiring attention. The dashboard features programme statistics showing student distribution (FYP1/FYP2) and proposal status breakdown with approval rate and pairing completion progress bars. A supervisor overview section displays capacity utilization across all supervisors. The right panel shows recent activity feed tracking proposal submissions, reviews, pairings, and announcements, along with upcoming deadline reminders for critical FYP milestones. Quick action buttons provide shortcuts to common tasks like reviewing proposals, managing announcements, viewing projects, and generating reports.

---

## 4.5.2 Announcements Management
**URL:** `/committee/announcements`

The Announcements Management screen enables FYP committee members to create, edit, and manage programme-wide announcements. Announcements can be filtered by status (Published, Draft, Archived) and target audience (All Students, FYP1 Only, FYP2 Only, specific programmes). Each announcement displays priority level (Low, Normal, High, Urgent) with color-coded indicators, title, content preview, target scope, view count, publication date, and expiration date. Committee members can edit existing announcements or archive them when no longer relevant. A summary section shows total announcements, published count, high-priority items, and aggregate view statistics.

---

## 4.5.3 Proposal Review Queue
**URL:** `/committee/proposals`

The Proposal Review Queue presents all student project proposals requiring committee evaluation. Proposals can be filtered by status (Pending Review, Under Review, Approved, Rejected, Revision Requested) and FYP cycle (FYP1/FYP2). A status summary bar shows the count of proposals at each review stage, allowing quick filtering by clicking on any status. Each proposal card displays the title, student name and ID, assigned supervisor, current status badge, FYP cycle, programme, version number, AI analysis score (if available), and submission date. The interface supports searching by title, student name, or supervisor name. Review history count indicates how many times each proposal has been reviewed.

---

## 4.5.4 Documents Management
**URL:** `/committee/documents`

The Documents Management screen allows committee members to upload and manage general FYP programme documents including templates, rubrics, handbooks, guidelines, and forms. Documents can be filtered by category and visibility level (Public, Students Only, Supervisors Only, Committee Only). A category summary bar shows document counts for each type with clickable filters. Each document card displays the title, description, category badge, visibility indicator, version number, file name, file size, download count, and last update date. Actions include viewing version history, editing metadata, downloading, and deleting documents. The system tracks download statistics across all documents.

---

## 4.5.5 Project & Pairing Overview
**URL:** `/committee/projects`

The Project & Pairing Overview screen provides a centralized view of all FYP projects and student-supervisor pairings. Quick stats cards display total projects, paired students, unpaired students, and high-risk projects. Projects can be filtered by FYP cycle, pairing status (Paired, Unpaired, Pending Approval), and project status (Not Started, In Progress, Completed, On Hold). Each project card shows a circular progress indicator, project title, student name, supervisor name (if paired), pairing status badge, project status badge, cycle, programme, and risk level for at-risk projects. Quick links provide access to unpaired students list, supervisor load analysis, and data export functionality.

---

## 4.5.6 Reports Module
**URL:** `/committee/reports`

The Reports Module enables committee members to generate comprehensive analytical reports for FYP programme management. Available report types include Progress Summary, Supervision Load Report, Pairing Status Report, Proposal Analysis, Milestone Tracking, and Risk Assessment. Each report type displays a description of the insights provided. Configurable filters allow specifying FYP cycle, programme, and date range for report generation. Quick action cards provide one-click access to commonly needed reports like FYP1 Progress, Load Analysis, and At-Risk Projects. A selected report preview shows the configured parameters before generation. Generated reports are accessible through the report history section for future reference.
